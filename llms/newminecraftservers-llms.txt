# NewMinecraftServers

> A directory of new Minecraft servers for Java and Bedrock Edition. Every listing is checked automatically and shows the server IP, whether it was online at its latest check, players online, the versions it accepts and its gamemodes. Newest servers are listed first on the home page.

Each server has a page at /server/<slug> with its IP, live status and join steps, a /stats tab with player-count history, and a /vote tab where players vote once a day. Offline servers are hidden from lists by default.
